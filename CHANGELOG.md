# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning.

## [1.0.0] - 2026-10-07

### Added

- Immutable, schema-versioned execution and delivery checkpoint records.
- Fenced claims with compare-and-swap revisions.
- Explicit recovery decisions for completed, in-flight, uncertain, delivering, and delivered work.
- Binding-conflict, payload-bound, persisted-state, and stale-owner validation.
- ESM, CommonJS, and TypeScript declaration entry points.
